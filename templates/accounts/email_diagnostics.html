Troubleshooting & Cloud Egress
  • If TCP Socket Connection Times Out: Cloud providers (like Render free tier) frequently drop or block outbound SMTP traffic on port 587/25 to prevent spam.
  • Solution 1 (HTTPS API): Add RESEND_API_KEY in Render Environment variables. Resend uses standard HTTPS port 443 which is never blocked and delivers in <200ms.
  • Solution 2 (SSL Port 465): Set EMAIL_PORT=465 and EMAIL_USE_SSL=True in Render Environment variables.
  • If SMTP Authentication Fails: For Gmail, ensure 2-Factor Authentication is active and use a generated 16-character App Password (without spaces) instead of your normal account password.
