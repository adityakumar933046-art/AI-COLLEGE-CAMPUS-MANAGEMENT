Google Cloud OAuth Setup Guide

Follow these steps in Google Cloud Console:

  1. Create or select a project in Google Cloud Console.
  2. Enable the Gmail API under APIs & Services.
  3. Under OAuth consent screen, select External, set Publishing status to Testing, and add your Gmail address as a Test User.
  4. Create an OAuth Client ID (Application type: Web application).
  5. Add Authorized Redirect URIs in your Google Cloud Console OAuth Client:
    1. For Gmail Sending Authorization:
    {{ redirect_uri }}
    2. For "Continue with Google" User Login:
    {{ google_login_redirect_uri }}
  6. Copy the Client ID and Client Secret into your Render Environment Variables as GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET.
